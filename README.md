# Charly’s Bakery Website

## Description
A responsive website showcasing Charly’s Bakery products, including cakes, cupcakes, and an order form.

## Installation
Clone the repository and open `index.html` in your browser.  
Or use VS Code with Live Server.

## Usage
- Navigate via the top menu (Home, About Us, Products, Order Form, Contact Us).
- Quick Links on the homepage jump directly to the product page.
- Hover effects highlight interactive elements.

## Features
- Responsive layout with media queries (480px and 768px breakpoints).
- External stylesheet for consistent design.
- Standardized colour scheme (cream, chocolate brown, raspberry pink, mint green, buttery yellow).
- Product showcase with images.
- Order form for customer requests.
